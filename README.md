# দ্য ইনসাইড রিপোর্ট বিডি (The Inside Report BD)

বাংলাদেশের প্রধান প্রধান সংবাদ মাধ্যমের সর্বশেষ খবর এক জায়গায় সহজে পড়ার আধুনিক রিয়্যাক্ট (React + TypeScript + Vite) অ্যাপ্লিকেশন।

## পোর্ট করা মূল ফিচারসমূহ (Ported Features)
- **রিয়েল-টাইম সংবাদ সংগ্রহ (Multi-source News Aggregation)**:
  - প্রথম আলো, ডেইলি স্টার, জাগো নিউজ, The Inside Report BD, আজকের পত্রিকা, বাংলাদেশ জার্নাল, বিডি২৪ লাইভ, আল জাজিরা (ইংরেজি)।
  - ক্লাউডফ্লেয়ার ওয়ার্কার এপিআই (`/api/news`) এবং আরএসএস২জেসন (RSS2JSON) ফলব্যাক সমন্বিত নিরবচ্ছিন্ন ডেটা লোডিং।
- **ফিল্টারিং এবং ক্যাটাগরি চিপস (Source Filtering)**:
  - নির্দিষ্ট পত্রিকার খবর আলাদাভাবে দেখার জন্য হরিজন্টাল স্ক্রলযোগ্য চিপস বার।
- **অনুসন্ধান (Real-time Search)**:
  - শিরোনাম ও সংবাদের সংক্ষিপ্ত বিবরণে তাৎক্ষণিক বাংলা ও ইংরেজি কীওয়ার্ড সার্চ।
- **সংরক্ষিত খবর (Bookmarks / Saved Articles)**:
  - পছন্দের সংবাদ পরে পড়ার জন্য অফলাইন লোকালস্টোরেজ (localStorage) বুকমার্কিং ব্যবস্থা।
- **ডার্ক ও লাইট থিম (Dark / Light Theme)**:
  - এক ক্লিকে ডার্ক মোড এবং লাইট মোডের মধ্যে রূপান্তর ও পছন্দ সংরক্ষণ।
- **স্বয়ংক্রিয় রিফ্রেশ (Auto-refresh & Manual Refresh)**:
  - প্রতি ৫ মিনিট পর পর স্বয়ংক্রিয় হালনাগাদ ও সাথে সাথে রিফ্রেশ করার বাটন।
- **বাংলা সংখ্যা ও সময় রূপান্তর (Bengali Localization)**:
  - বাংলা সংখ্যা এবং আপেক্ষিক সময় (যেমন: "এইমাত্র", "৫ মিনিট আগে", "২ ঘণ্টা আগে", "১ দিন আগে") প্রদর্শন।

## প্রযুক্তি (Tech Stack)
- React 18
- TypeScript
- Vite
- Mobile-first responsive CSS with CSS custom properties (theme tokens)
